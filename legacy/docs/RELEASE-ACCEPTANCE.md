## Environment and promotion boundaries

Development observations use arm64 macOS 27.0 beta build 26A5406e with command-line tools; installed-HAL observations above use the specifically recorded macOS 15.7.9 build 24G830 arm64 runners. Universal cross-compilation/signature checks and reported Rosetta execution are distinct from native Intel behavior and do not establish all supported OS/driver combinations. The separately reproduced development-host BlackHole 0.5.0 registration hang remains an unresolved compatibility result.

The reference EULA has been accepted after explicit user approval; the newly observed vendor-driver installation is a separate pending boundary. Opening the RaveLink test-driver installer is approved. Administrator authentication, capture privacy consent and distribution service credentials remain explicit user/environment boundaries. The preserved signed bundles include `build/signed-16abe9a/RaveLink.app`, `build/signed-universal-784e38f-modified/RaveLink.app` and the separately reviewed clean `build/signed-universal-f733a8c/RaveLink.app`; ordinary `build/RaveLink.app` is a separate development artifact and must not be represented as any preserved signed revision.

Every promotion needs the exact source/binary hashes, OS/build, device IDs, rates/buffers, test setup, measured result and retained independent artifacts. Keep failed original observations immutable. Screenshots, synthetic controls, local test summaries and successful signing cannot close runtime fidelity, audio integrity, notarization or production release gates.
